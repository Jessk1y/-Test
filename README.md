# Многофункциональный калькулятор

Это веб-приложение представляет собой многофункциональный калькулятор с расширенными возможностями.

## Возможности

- **Стандартный калькулятор**: основные арифметические операции и научные функции
- **Конвертер величин**: преобразование между различными единицами измерения
- **Решение уравнений**: линейные и квадратные уравнения
- **История вычислений**: сохранение и экспорт предыдущих вычислений
- **Настройки интерфейса**: изменение темы, размера шрифта и языка

## Установка и запуск

1. Склонируйте репозиторий
2. Откройте файл `index.html` в веб-браузере

Альтернативно, можно запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере: http://localhost:8000

## Использование

### Калькулятор
- Используйте кнопки или клавиатуру для ввода выражений
- Поддерживаются научные функции: sin, cos, tan, log, ln, sqrt, x^y, π, e

### Конвертер
- Выберите тип конвертации (длина, масса, температура)
- Выберите единицы измерения "из" и "в"
- Введите значение и нажмите "Конвертировать"

### Уравнения
- Введите коэффициенты линейного или квадратного уравнения
- Нажмите "Решить" для получения результата

### История
- Все вычисления сохраняются автоматически
- Можно очистить историю или экспортировать в JSON/CSV

### Настройки
- Выберите тему (светлая/тёмная)
- Настройте размер шрифта
- Выберите язык интерфейса
